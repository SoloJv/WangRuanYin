🌐 Website mode open the REAL site — the features are added there, like the extension

Type a website and click Open website: the actual website opens in a new tab — nothing is fetched, proxied or re-rendered, so every image, link and script works exactly like the browser extension. To add 王软音's features (pinyin, translations, HSK) to that page, drag the link below to your bookmarks bar once, then click it on the page — the same floating panel as the extension appears. The toggles above are baked into this link; change them here and it updates.
