Pinyin annotations, translations & HSK colour coding — web app edition.

Pinyin annotations Show pinyin under every Chinese character
Sentence translation One translation row under each sentence (Google, needs internet)
HSK colour coding
Colour Chinese characters by their lowest HSK level · tap a colour in the legend to hide/show that level
Read page aloud
Reads every annotated sentence aloud with the Chinese browser voice

🌐 Website mode use Wangruanyin on any website, in a separate tab

Type a website (e.g. https://zh.wikipedia.org), open it in a new tab, then apply 王软音 to it. First-time setup: drag the 王软音 link below to your browser's bookmarks bar (or copy it). Then open the website and click the bookmark — a floating panel appears with all the toggles, and pinyin, translations & HSK colours are applied to the page.

王软音 · Wangruanyin

⚠️ You opened the app from disk (file://). The bookmarklet will use the published GitHub bases located at https://solojv.github.io/WangRuanYin/ and the jsDelivr CDN — both need the repository to be public (see the README and the reachability check below). For local development, run python -m http.server 8000 inside the Wangruanyin-WebApp folder and open http://localhost:8000/.

The toggles above (pinyin, translation, language, HSK) are baked into the bookmarklet — change them here and the link updates automatically. The bookmark applies them when clicked; "Translate selection" and the other toggles can be fine-tuned from the floating panel on the website (and are remembered per site). This app is hosted on GitHub Pages at https://solojv.github.io/WangRuanYin/ — the reachability check below confirms which sources the bookmarklet can load the engine from. Addresses without a protocol get https:// added.
