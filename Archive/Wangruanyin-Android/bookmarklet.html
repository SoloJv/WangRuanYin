网软音 · Wangruanyin — Bookmarklet

Tap Copy bookmarklet, then add it as a bookmark URL in your mobile browser (Chrome/Edge/Brave/Opera/Firefox Android). On any Chinese page, select some Chinese text and tap the bookmark to see a floating panel with pinyin + a translation.

  1. Tap Copy bookmarklet.
  2. Whichever browser: open ⋮ → Bookmarks / Add bookmark.
  3. Paste into the bookmark URL field. Name it “Wangruanyin”.
  4. On a Chinese page, long-press to select Chinese text, then tap the bookmark.
