How to install on Android (add to home screen)
1. Put this folder on the phone or host it (e.g. on a local network / static host).
2. Open index.html in Chrome / Edge / Brave / Firefox for Android.
3. Open the ⋮ menu → Add to home screen. A full-screen app icon is created.
4. Tap the icon to launch Wangruanyin like an app (works offline except translations).
